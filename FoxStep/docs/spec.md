# 專案規格：狐步 FoxStep — 妖狐專案推進板

> 一個像大富翁一樣的專案推進網頁。每個專案是一個世界，每一天是一格，可愛的妖狐每推進一天就往前跳一格。

---

## 1. 目標與受眾

- **目標**：把「專案進度」變成一趟旅程，讓每天的推進有儀式感，也留下每天的紀錄。
- **受眾**：自己（個人專案、學習計畫、作品製作），也適合學生、接案者。
- **核心體驗**：建立專案 → 進入世界 → 每天推進 → 妖狐前進一格 → 點格子寫下當天的收穫。

---

## 2. 技術限制與檔案結構

| 項目 | 規定 |
|---|---|
| 檔案 | **只有一個 `index.html`**，CSS 與 JavaScript 全部內嵌 |
| 外部資源 | 不依賴任何框架；字體可選用 Google Fonts（如 `Zen Maru Gothic`） |
| 圖像 | 妖狐、格子、背景全部用 **內嵌 SVG + CSS** 繪製，不使用外部圖片 |
| 資料儲存 | `localStorage`（讀寫都要包 `try/catch`，失敗時網頁仍可運作，只是不保存） |
| 後端 | 無 |
| 支援 | 桌機 + 手機（RWD，最窄 360px） |

---

## 3. 畫面總覽

網頁有三個畫面（用 JS 切換，不換頁）：

1. **首頁：專案大廳**（狐狸神社）
2. **世界頁：大富翁棋盤**
3. **格子詳情視窗**（Modal）

---

## 4. 首頁：專案大廳

### 4.1 版面
- 頂部：網站標題「狐步 FoxStep」＋ 一隻待機中的妖狐（輕輕上下浮動、尾巴擺動）。
- 中間：**專案卡片列表**（Grid 排列）。
- 右下角或列表最後：**「＋ 開啟新專案」** 卡片。

### 4.2 專案卡片內容
- 專案名稱
- 世界主題小圖示（見 §5.4）
- 進度條：`已推進 X / 總天數 Y`
- 截止日（Deadline）與 **剩餘天數**（例：「還有 12 天」）
- 狀態標籤：
  - 🟢 **順利**：已推進天數 ≥ 已經過天數
  - 🟡 **落後**：已推進天數 < 已經過天數
  - 🏁 **完成**：妖狐抵達終點
  - ⏰ **逾期**：已過截止日但未完成
- 點擊卡片 → 進入該專案的世界頁。
- 卡片右上角「⋯」選單：編輯、刪除（刪除前需確認）。

### 4.3 開啟新專案（Modal 表單）
| 欄位 | 類型 | 必填 | 說明 |
|---|---|---|---|
| 專案名稱 | 文字 | ✅ | 最多 30 字 |
| 開始日期 | 日期 | ✅ | 預設今天 |
| 截止日期（Deadline） | 日期 | ✅ | 必須晚於開始日期 |
| 世界主題 | 選擇 | ⭕ | 森林／櫻花／雪山／夜祭，未選則隨機 |
| 專案目標 | 多行文字 | ⭕ | 一句話描述想完成什麼 |

- 系統自動計算 **總天數 = 截止日 − 開始日 + 1**，即時顯示「這趟旅程共 N 格」。
- 總天數限制：1 ～ 365 天，超出顯示錯誤提示。

## 5. 世界頁：大富翁棋盤

### 5.1 頂部資訊列
- ← 返回大廳
- 專案名稱、專案目標
- 倒數：「距離 Deadline 還有 N 天」
- 進度：`第 X 格 / 共 Y 格`
- 主要按鈕：**「🦊 推進今天」**

### 5.2 棋盤排列規則
- **天數 ≤ 40**：大富翁經典 **環形排列**（格子沿長方形外圈繞一圈），中間空白區放專案名稱與妖狐神社插圖。
- **天數 > 40**：**蛇形排列**（左→右、下一行右→左，交替），可上下捲動。
- 手機版一律使用蛇形排列，每行 4～5 格。
- 格子之間用小路（虛線或石板路）連接，讓路徑看得出方向。

### 5.3 格子種類
| 格子 | 位置 | 外觀 |
|---|---|---|
| 起點 | 第 1 格 | 寫「出發」，有小燈籠 |
| 一般格 | 每天一格 | 顯示「Day N」與日期 |
| 神社格 | 每第 7 格 | 小鳥居圖示，代表一週檢查點 |
| 終點 | 最後一格 | 大鳥居＋「Deadline」字樣 |

### 5.4 格子狀態
| 狀態 | 條件 | 外觀 |
|---|---|---|
| 未來 | 還沒走到 | 淡色、半透明 |
| 已走過・有紀錄 | 有填任一欄位 | 亮色＋小狐狸腳印 🐾 |
| 已走過・無紀錄 | 推進了但沒寫 | 亮色＋小問號 |
| 目前位置 | 妖狐所在格 | 發光外框 |
| 今天 | 對應今天的日期 | 格子上方小旗子 🚩 |

> 「今天」和「妖狐位置」不同時，視覺上就能看出是超前還是落後。

### 5.5 世界主題（配色＋背景裝飾）
| 主題 | 主色 | 背景裝飾 |
|---|---|---|
| 🌲 森林 | 綠＋木頭棕 | 樹、蘑菇、螢火蟲 |
| 🌸 櫻花 | 粉＋白 | 飄落花瓣動畫 |
| 🏔️ 雪山 | 藍＋白 | 飄雪動畫 |
| 🏮 夜祭 | 深藍＋橘紅 | 燈籠、星星 |

## 6. 妖狐角色

### 6.1 外觀
- 原創角色：白色或橘色小狐狸，**大眼睛、九條（或三條）蓬鬆尾巴**，額頭有紅色印記，頸上掛小鈴鐺。
- 以內嵌 SVG 繪製，風格圓潤可愛（Q 版）。

### 6.2 動畫
| 情境 | 動作 |
|---|---|
| 待機 | 上下輕微浮動、尾巴左右擺 |
| 推進 | **跳躍**到下一格（拋物線動畫，約 0.6 秒），落地時有小星星或狐火特效 |
| 抵達神社格 | 轉一圈＋顯示「一週達成！」 |
| 抵達終點 | 撒花／狐火煙火＋「旅程完成！」 |
| 落後時 | 表情變成擔心的樣子 |
| 順利時 | 開心瞇眼 |

### 6.3 妖狐對話泡泡
推進後妖狐隨機說一句鼓勵的話，例如：
- 「又前進一步了！」
- 「今天也辛苦了～」
- 「離鳥居越來越近囉！」

---

## 7. 推進規則

- 按下 **「🦊 推進今天」**：妖狐前進一格，並 **自動打開該格的詳情視窗** 讓使用者填寫。
- **每個日曆日只能推進一次**（以本地日期判斷），推進後按鈕變成「今天已推進 ✓」。
- 若落後（妖狐位置 < 今天），允許 **「補推進」**，一次一格，直到追上今天。
- 不可超前今天的日期。
- 妖狐到達終點後，按鈕變成「🏁 旅程完成」。
- 提供「撤銷上一步」（只能撤銷最近一次推進，需確認）。

## 8. 格子詳情視窗

點擊任何 **已走過的格子** 打開（未來的格子點了只顯示「還沒走到這裡喔」）。

### 8.1 版面
- 標題：`Day N · 2026/10/19（一）`
- 三個區塊：

| 區塊 | 圖示 | 提示文字 | 預設顯示 |
|---|---|---|---|
| **我解決了什麼** | ✅ | 今天完成了哪些事？ | 顯示 |
| **我發現了什麼** | 💡 | 學到什麼、有什麼新想法？ | 顯示 |
| **我碰到了什麼障礙** | 🌑 | 卡住的地方、困難、心情 | **隱藏** |

### 8.2 隱藏的「障礙」欄位
- 預設收合，只顯示一個封印樣式的卡片：「🔒 封印的障礙（點擊解開）」。
- 點擊後展開輸入框，再點一次重新封印。
- 已有內容的格子，在棋盤上 **不顯示** 障礙內容，只有打開詳情並主動解開才看得到。
- 用意：可以誠實記錄困難，但平常瀏覽時不會一直看到負面內容。

### 8.3 操作
- 文字自動儲存（停止輸入 0.5 秒後存檔），顯示「已儲存」小提示。
- 底部：上一格 ◀ ／ ▶ 下一格，方便連續回顧。
- 關閉：右上角 ✕、點遮罩、按 Esc。

## 9. 資料結構（localStorage）

Key：`foxstep.v1`

```json
{
  "projects": [
    {
      "id": "p_1729332000000",
      "name": "作品集網站",
      "goal": "完成個人作品集並上線",
      "theme": "sakura",
      "startDate": "2026-10-19",
      "deadline": "2026-11-15",
      "position": 3,
      "lastAdvanceDate": "2026-10-21",
      "createdAt": "2026-10-19T18:42:00+08:00",
      "steps": {
        "1": { "solved": "", "found": "", "obstacle": "" },
        "2": { "solved": "完成首頁版面", "found": "Grid 比 Flex 適合這裡", "obstacle": "手機版跑版" }
      }
    }
  ]
}
```

- `position`：妖狐目前在第幾格（0 = 還在起點前，尚未推進）。
- `steps`：以格子編號為 key，只存有走過的格子。

### 9.1 匯出／匯入
- 大廳頁提供「匯出全部資料（JSON）」與「匯入資料」按鈕，方便備份或換電腦。

## 10. 視覺風格

- **整體感覺**：日系、溫暖、可愛、手繪感。
- **字體**：標題用圓體（如 `Zen Maru Gothic`），內文用系統字體。
- **圓角**：卡片與格子都用大圓角（12～16px）。
- **陰影**：柔和、帶一點主題色。
- **深色模式**：支援 `prefers-color-scheme: dark`，夜祭主題可作為深色預設。
- **動效**：尊重 `prefers-reduced-motion`，開啟時取消跳躍與飄落動畫，改為淡入淡出。

## 11. 驗收標準

- [ ] 只有一個 `index.html`，直接用瀏覽器打開即可運作。
- [ ] 能新增、編輯、刪除專案，資料重新整理後仍在。
- [ ] 格子數量 = 開始日到截止日的天數，排列正確（≤40 環形、>40 蛇形）。
- [ ] 按「推進今天」妖狐會跳到下一格，同一天不能推進第二次。
- [ ] 落後時可以補推進，但不能超過今天。
- [ ] 每格有三個欄位，「障礙」預設隱藏、可解開／封印。
- [ ] 第 7、14、21… 格顯示神社，終點顯示大鳥居，抵達時有特效。
- [ ] 手機寬度 360px 下可以正常操作，沒有橫向捲軸。
- [ ] 可匯出、匯入 JSON 資料。

## 12. 之後可以加的功能（v2 想法）

- 🎲 **事件卡**：推進時偶爾抽到「狐狸的祝福」或「小挑戰」卡片。
- 🏆 **成就徽章**：連續推進 7 天、填滿所有紀錄等。
- 📜 **旅程回顧**：專案完成後產生一張總結卷軸，列出所有「解決」與「發現」。
- 🎨 **妖狐換裝**：用完成的專案數解鎖不同顏色或配件。
